# Bridgit website

Buildless static site. Serve dist/ locally or use its registered owner-private Sites project. No runtime dependencies, form submissions, external fonts or analytics.

Configuration: dist/site-config.json records pending domain, contacts and Play URL. No public domain is invented. Before public launch, replace the preview status and legal drafts with confirmed facts, update Open Graph URLs and add canonical/sitemap URLs for the registered domain. Only then change noindex/robots. There is no functional hosted-account deletion backend.

The interactive cards are a local concept selector, not a simulation of a real device connection. Every planned appliance is labeled. Do not add a Play badge until the listing exists.

No custom domain or DNS changes were performed.
