How to install

Install steps & file verification
  1. Download the APK on a compatible Android device.
  2. If Android asks, allow this browser or file app to install apps. Only install APKs from sources you trust.
  3. Open the APK and follow Android’s installation prompt. You can disable that install-source permission afterward.
  4. Open bridgit, connect Tailscale, review the permissions and pair an agent. Keep the listener private.
