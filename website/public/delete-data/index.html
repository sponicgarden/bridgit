BRIDGIT / DELETE DATA

Your BRIDGIT data

Local controls for the current personal build.

Stop new access

On the phone, stop the listener. Remove an agent or rotate its key to invalidate future requests. Disabling a capability currently affects subsequent requests; immediate cancellation is a planned release requirement.

Delete local records

Use Remove for each agent and Clear log for request history. For a complete local reset, use Android’s app-storage clear control for BRIDGIT or uninstall the app. This removes pairing and app-local records. You will need to pair agents again.

What this does not delete

Original gallery photos, exported log files and photos/audio already transferred to agents remain outside BRIDGIT’s local reset. Delete those through Android storage, the export destination, or the agent/provider that holds the copy.

Online accounts

The current BRIDGIT build does not create a BRIDGIT online account. This page is not a hosted-account deletion form. If future hosted services add accounts, release will include in-app and external account-deletion request paths with published retention details.

Questions

A verified public support/privacy contact will be added after domain and mailbox setup. No requests are collected by this preview.
