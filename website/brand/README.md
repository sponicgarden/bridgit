# Bridgit identity

Selected direction: 01, lowercase Bricolage Grotesque Bold with optical spacing. `public/assets/logo-wordmark.svg` contains outlined glyphs, so it requires no installed font or network request. `logo-mark.svg` and `favicon.svg` contain the unchanged Android launcher foreground on its original #2B1834 background, cropped to the central 72dp launcher viewport.

Raster copies in `public/assets/`, rendered from those SVGs:

- Icon: `logo-mark-1024.png` and `logo-mark-512.png` (rounded, transparent corners), `logo-mark-square-1024.png` (full square, for platforms that apply their own mask), `logo-mark-1024.jpg` (full square).
- Wordmark: `logo-wordmark.png` (plum, transparent), `logo-wordmark-white.png` (white, transparent, for dark backgrounds), `logo-wordmark.jpg` (plum on warm white), `logo-wordmark-white.jpg` (white on plum), and `logo-wordmark-white.svg`.

Palette: plum #2B1834, lavender #BB8CF0, sandstone #F3D9AB, amber #FFBB70, warm white #FBF5EB. Dark plum carries text; lavender, sandstone and amber are accents and surfaces.

The Android package ID, signing key and agent protocol identifiers are compatibility identifiers and retain their historical spelling. The displayed brand is bridgit.
